# ⚓ Морской бой — полная коллекция

Морской бой в 3-х версиях: консольная (Python), графическая (Web) и упрощённая для обучения.

[![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)](https://python.org)

---

## 🎮 Версии

| Версия | Описание | Запуск |
|--------|----------|--------|
| **Python (полная)** | Меню, настройки, ИИ 3-х уровней, статистика | `python python/sea_battle.py` |
| **Python (простая)** | Базовый морской бой для обучения | `python python/sea_battle_simple.py` |
| **Web (графика)** | Кликабельные клетки, анимация, адаптив | Открыть `web/index.html` в браузере |
